# Technical & Visual Artifacts

## Artifact 1: Segment Occupancy Curves (Planned)
* **What it is:** A line chart showing average monthly room occupancy for the low, medium, and high seasonality commune groups (2013–2019).
* **Technical Skill:** Data cleaning, feature engineering, and visualization.
* **Business Insight:** Proves that alpine resorts have dual peaks (winter and summer) while cities are flat, justifying why we need different models for different destinations.

## Artifact 2: Forecast Error Table (Planned)
* **What it is:** A table comparing MASE and RMSE scores of the seasonal naive baseline, SARIMA, and machine learning models.
* **Technical Skill:** Time series cross-validation and scale-free error measurement.
* **Business Insight:** Shows which model a hotel manager should trust for 1-month vs. 12-month planning.
